Most AI tool sites read like a brochure.

We built a book.

agents.lunaos.ai is structured as eleven chapters:
Frontispiece → Lexicon → Grammar → Etymology → Install → Playground → Manifesto → Skills → Showcase → Architecture → Hospital → Blog → vs.

It's set in Instrument Serif, Inter Tight, and JetBrains Mono.
It has an actual etymology section explaining where pipes came from.
It has a /play page that validates your input against the real 356-verb lexicon as you type.
It has a /architecture page with the whole system rendered in 3D Three.js, drag to orbit.
It has a /hospital page with 21 stack-aware doctor commands across five wings.

The whole site is static. Cloudflare Pages. Sub-100ms response from anywhere.
No analytics. No cookies. No tracking. No newsletter pop-up.

Half the people who land on it think it's a programming language.
The other half realize it is.
