# 🌙 Luna Agent Commands

Global Claude Code command shortcuts for the Luna development workflow. Use from any project!

## Setup

### 1. Install Luna Agents (One-Time Setup)
```bash
# Create global Luna agents directory
mkdir -p ~/luna-agents

# Place all 10 Luna agent .md files in ~/luna-agents/
```

### 2. Install Commands (One-Time Setup)
```bash
# Create global commands directory
mkdir -p ~/.claude/commands

# Place all these command .md files in ~/.claude/commands/
```

### 3. Use Anywhere!
```bash
# Navigate to ANY project
cd /path/to/any-project

# Run Luna commands
luna-requirements
luna-design
luna-plan
# ... etc
```

## Complete Workflow

Run commands in order for full development cycle:

```bash
luna-requirements   # 1. Analyze & generate requirements
luna-design         # 2. Create technical design
luna-plan           # 3. Break into tasks
luna-execute        # 4. Implement (run multiple times)
luna-review         # 5. Code review
luna-test           # 6. Test & validate
luna-deploy         # 7. Deploy to production
luna-docs           # 8. Generate documentation
luna-monitor        # 9. Set up monitoring
luna-review-launch  # 10. Post-launch review (after 7 days)
```

## Available Commands

| Command | Purpose | Output Location |
|---------|---------|-----------------|
| `luna-requirements` | Analyze codebase & generate requirements | `.luna/{current-project}/requirements.md` |
| `luna-design` | Create technical design | `.luna/{current-project}/design.md` |
| `luna-plan` | Break design into tasks | `.luna/{current-project}/implementation-plan.md` |
| `luna-execute` | Implement tasks | Code + updated plan |
| `luna-review` | Review code quality | `.luna/{current-project}/code-review-report.md` |
| `luna-test` | Run tests & validate | `.luna/{current-project}/test-validation-report.md` |
| `luna-deploy` | Deploy to production | `.luna/{current-project}/deployment-report.md` |
| `luna-docs` | Generate documentation | `docs/` directory |
| `luna-monitor` | Set up monitoring | `.luna/{current-project}/monitoring-observability-report.md` |
| `luna-review-launch` | Post-launch analysis | `.luna/{current-project}/post-launch-review.md` |

## How It Works

1. **Commands reference global agents**: `~/luna-agents/luna-*.md`
2. **Agents detect current project**: Automatically uses current directory name
3. **Files created locally**: In `.luna/{current-project}/` of current directory
4. **Use in any project**: Same commands work everywhere!

## Directory Structure Per Project

When you run Luna commands, each project gets its own `.luna/` folder:

```
your-project/
├── .luna/                        # Created automatically
│   └── your-project/             # Project folder name
│       ├── requirements.md
│       ├── design.md
│       ├── implementation-plan.md
│       ├── code-review-report.md
│       ├── test-validation-report.md
│       ├── deployment-report.md
│       ├── monitoring-observability-report.md
│       └── post-launch-review.md
├── docs/                         # Generated by luna-docs
└── src/                          # Your source code
```

## Tips

1. **One-Time Setup**: Install agents and commands once, use everywhere

2. **Project Detection**: Luna automatically detects the current project name from the directory

3. **Scope Consistency**: Always use the same scope (project or feature name) across all commands in a workflow

4. **Task Execution Loop**: Run `luna-execute` multiple times until all tasks are complete

5. **Skip Steps**: You don't need to run all commands for small changes

6. **Parallel Features**: Work on multiple features by using different feature names

7. **Multiple Projects**: Switch between projects just by changing directories

## Troubleshooting

### Command Not Found
Make sure command files are in your commands directory (e.g., `~/.config/claude/commands/`)

### Agent Not Found
Verify `~/luna-agents/` folder contains all 10 agent .md files

### Files Not Found
Ensure you ran previous commands in the workflow (e.g., run `luna-requirements` before `luna-design`)

### Wrong Project Files
Check you're in the correct project directory with `pwd`
